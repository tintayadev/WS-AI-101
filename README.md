# Crea tu primera IA

Mini curso práctico de introducción a Inteligencia Artificial.

Programa desarrollado por Wasi Space en colaboración con Nos Gusta la Ciencia.

## Sesiones

- Session 1: Cómo aprende una máquina
- Session 2: Entrenar, probar y mejorar modelos
- Session 3: De modelo a proyecto interactivo

## Contenido

Cada sesión incluye una presentación web interactiva construida con HTML, CSS y JavaScript.
