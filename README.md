# Crea tu primera IA

Mini curso práctico de introducción a Inteligencia Artificial, desarrollado por **Wasi Space** en colaboración con **Nos Gusta la Ciencia**.

La idea del curso es aprender IA de forma práctica: entender cómo aprende un modelo, entrenar uno propio y luego utilizarlo dentro de un pequeño proyecto interactivo.

## Live

https://tintayadev.github.io/WS-AI-101/

## Sesiones

### Sesión 1 — Cómo aprende una máquina?

Introducción a Inteligencia Artificial y Machine Learning.

Temas principales:

- IA más allá de los chatbots
- datos, clases y datasets
- cómo funciona el entrenamiento de un modelo
- importancia de la variedad y calidad de los datos
- sesgos y errores de clasificación
- primer experimento con Teachable Machine
- vistazo rápido a tokens y modelos de lenguaje

Slides:

https://tintayadev.github.io/WS-AI-101/session-1/

---

### Sesión 2 — Entrenar, probar y mejorar

Cada participante construye su propio modelo de clasificación de imágenes.

Temas principales:

- preparación del dataset
- entrenamiento con Teachable Machine
- confianza de las predicciones
- pruebas con datos nuevos
- cómo encontrar errores en un modelo
- mejorar el dataset y reentrenar
- exportar y compartir modelos

Slides:

https://tintayadev.github.io/WS-AI-101/session-2/

---

### Sesión 3 — De modelo a proyecto

Usamos las predicciones de nuestro modelo para crear una experiencia interactiva.

Temas principales:

- introducción a Scratch
- conectar Teachable Machine con TM2Scratch
- convertir predicciones en acciones
- juegos y experiencias interactivas
- clasificación de imágenes y sonidos
- modelos de poses
- siguientes pasos hacia web, TensorFlow.js y proyectos más avanzados

Slides:

https://tintayadev.github.io/WS-AI-101/session-3/
